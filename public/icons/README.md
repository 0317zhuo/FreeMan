# 社交平台图标来源

微信、QQ、Telegram、X 图标来自 [Remix Icon v4.6.0](https://github.com/Remix-Design/RemixIcon/tree/v4.6.0/icons/Logos)，使用单色 SVG，与网站的等宽终端风格保持一致。

| 本地文件 | 上游文件 |
| --- | --- |
| `wechat.svg` | `wechat-fill.svg` |
| `qq.svg` | `qq-fill.svg` |
| `telegram.svg` | `telegram-fill.svg` |
| `x.svg` | `twitter-x-fill.svg` |

图标来自 Remix Icon 项目，v4.6.0 使用 Apache License 2.0；许可全文保存在同目录 `LICENSE`。保留原始路径数据。

## 本轮新增图标

- `discord.svg`、`openai.svg`：Remix Icon v4.6.0 的 `icons/Logos/discord-fill.svg`、`openai-fill.svg`。
- `rag.svg`：Remix Icon v4.6.0 的 `icons/Device/database-2-line.svg`，作为 RAG 能力的通用数据库图标，不表示品牌。
- `react.svg`、`nextdotjs.svg`、`typescript.svg`、`nodedotjs.svg`、`python.svg`、`postgresql.svg`、`googlegemini.svg`、`git.svg`、`docker.svg`、`vercel.svg`：来自 [Simple Icons v16.0.0](https://github.com/simple-icons/simple-icons/tree/16.0.0/icons)，保持上游原始 SVG 路径，使用单色展示。
- `rust.svg`、`tailwindcss.svg`、`hono.svg`、`trpc.svg`、`nestjs.svg`、`drizzle.svg`、`redis.svg`、`rabbitmq.svg`、`elasticsearch.svg`、`githubactions.svg`、`langchain.svg`、`claude.svg`：来自 [Simple Icons v16.0.0](https://github.com/simple-icons/simple-icons/tree/16.0.0/icons)。`opencode.svg` 来自 [Simple Icons 开发分支](https://github.com/simple-icons/simple-icons/blob/develop/icons/opencode.svg)。
- 技术栈中的 ZooKeeper 使用 `rag.svg` 通用数据库图标，因为 Simple Icons 没有 ZooKeeper 品牌图标；Claude Code 使用 Claude 图标，Codex 使用 OpenAI 图标。
- Simple Icons 的 CC0 许可与品牌使用说明保存在 `SIMPLE-ICONS-LICENSE.md`；图标及所代表品牌的商标权归各自权利人，使用前可查阅项目逐图标的品牌指南与许可。
