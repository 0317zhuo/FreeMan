# 首页验收记录

本轮只开发落地页；参考 `LANDING_PROMPT.md` 的十区域与交互要求。验收使用生产构建的实际浏览器渲染，未添加测试框架或测试依赖。

## 预览

- 本轮启动的生产预览：http://127.0.0.1:3001 。
- 重启：`pnpm build` 后执行 `pnpm start --port 3001 --hostname 127.0.0.1`。
- 开发：`pnpm dev`，已有开发服务可访问 http://localhost:3000 。既有服务以 localhost 启动时应沿用该地址，避免 Next.js 开发资源的跨来源限制。

## 检查结果

- `pnpm lint`、`pnpm build`、`git diff --check` 已通过。构建仅产生首页及 Next.js 默认 not-found，无新增业务/详情路由。
- 生产预览控制台未出现警告或错误；所有图片完成加载；所有当前锚点均对应真实区块；无空链接、未完成路由链接、伪造外部账号或群邀请。
- 五种屏宽的 `document.documentElement.scrollWidth` 分别为 1440、1024、768、390、320，均等于视口宽度，无整页横向滚动。
- 所有 38 个当前可见业务、详情、社交、社区与页脚按钮均逐项点击并获得包含目标名称的状态提示。
- 微信、QQ、Telegram、X 分别反馈「联系方式待配置」；Discord、Telegram、QQ 社区分别反馈「邀请链接待配置」。
- 移动菜单包含六项完整导航，Enter 可打开，选择业务入口后关闭并提示；Escape 可关闭菜单，焦点返回开关，开关具有可见焦点。
- 四市场 Tab 实际切换资产与小计；ArrowRight、Home、End 已在浏览器验证自动选中与焦点变化；ArrowLeft 与循环规则经代码检查。所有 `aria-controls` 均指向存在的元素。
- 状态通知使用 `role="status"`，关闭按钮与 Escape 均可关闭；键盘关闭后焦点返回来源按钮。
- 静态示例金额另通过 Node 断言核对：美股 ¥86,620、加密 ¥85,910、A股 ¥35,000、港股 ¥52,780，总计 ¥260,310。切换四个市场时总额保持不变。占比基于人民币换算值；逐项与小计显示一位小数并说明取整差异。
- 减少动态效果：已检查浏览器实际加载的媒体规则与源码，`prefers-reduced-motion: reduce` 下关闭页面动画、过渡与平滑滚动，内容不依赖入场脚本才可见。当前系统偏好为非 reduce，本轮未切换用户系统设置或模拟该偏好。
- 已查看五种屏宽的整页截图及 320px 关键区块截图，修正课程插画遮挡和跳转链接在整页截图中的显示问题。桌面贡献者两行八列，中屏与 390px 四列，320px 两列。

## 替换资料

`app/landing-data.ts` 集中保存入口名称/拟用路径/可用状态、社交与社区资料、技术矩阵、项目、课程、贡献者，以及示例持仓数量/价格/币种/汇率和计算函数。实际页面上线后才启用入口；真实链接使用 `href`，微信与 QQ 联系方式可使用 `account`。

真实个人资料、作品地址、课程内容、社交账号、三平台群邀请及贡献者名单尚待用户替换。首页示例并不表示真实资产、客户案例或已开放服务。详情页、支付、消息发送、实时行情与中转服务后端均留到后续开发。
